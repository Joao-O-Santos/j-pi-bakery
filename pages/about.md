# About the Bakery

J's Pi Bakery is the umbrella for João Oliveira Santos's small Pi extensions and closely related companion tools.

The name is deliberately unserious. The design preference is not:

- small interfaces;
- explicit behavior;
- ordinary files and tools where possible;
- composition with the wider Pi ecosystem instead of copying it;
- enough whimsy that quota exhaustion can reasonably say `AUCH!!`.

## What belongs here?

A project belongs in the Bakery when it is maintained here as one of João's Pi extensions or companion tools.

External dependencies do not become Bakery projects merely because a Bakery tool uses them. For example, Pi-lease imports the upstream [`pi-chrome-use`](https://github.com/citrolabs/pi-chrome-use) extension. That project remains its authors' work.

## The oven

This site is deliberately boring underneath: Markdown, HTML, CSS, GNU-ish Make, and GitLab Pages, built with [`make it_stop`](https://gitlab.com/Joao-O-Santos/make-it-stop).
