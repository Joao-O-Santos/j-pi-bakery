# Fresh from the oven

**J's Pi Bakery** is a small collection of Pi extensions and companion tools made by João Oliveira Santos.

The common recipe is intentionally simple: add one useful capability, keep the surface small, and avoid turning Pi into a framework it did not ask to become.

<div class="notice">
<strong>Small-batch Pi extensions.</strong> Built independently for <a href="https://pi.dev/">Pi</a>; not an official Pi project.
</div>

## The pies

<div class="card-grid">

  <article class="card">

    <p><a class="button" href="https://gitlab.com/Joao-O-Santos/pi-auch/-/blob/main/README.md">Documentation</a> <a href="https://gitlab.com/Joao-O-Santos/pi-auch">Source</a></p>

    <h3>pi-pew-pew</h3>

    <p><a class="button" href="https://gitlab.com/Joao-O-Santos/pi-pew-pew/-/blob/main/README.md">Documentation</a> <a href="https://gitlab.com/Joao-O-Santos/pi-pew-pew">Source</a></p>

  <article class="card">
