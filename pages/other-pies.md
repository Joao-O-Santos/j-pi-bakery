# Other delicious pies

The Pi community has plenty more in the oven. This shelf highlights projects that J's Pi Bakery uses or enjoys alongside its own extensions.

## Pi

The coding agent at the centre of everything baked here: small, extensible, and comfortable with tools.

- **Website:** [pi.dev](https://pi.dev/)

## pi-chrome-use

An upstream browser extension used by Pi-lease. It provides the browser integration; Pi-lease supplies a visible, dedicated Chromium profile and a convenient launcher.

- **Source:** [github.com/citrolabs/pi-chrome-use](https://github.com/citrolabs/pi-chrome-use)

## Plannotator for Pi

A visual plan-review companion for Pi. It adds a file-based plan mode with a browser UI for reviewing, annotating, and approving agent plans before implementation.

- **Install:** `pi install npm:@plannotator/pi-extension`
- **Source:** [github.com/backnotprop/plannotator](https://github.com/backnotprop/plannotator)
